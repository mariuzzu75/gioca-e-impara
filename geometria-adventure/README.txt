COME PUBBLICARLO SU GITHUB PAGES
1. Nel repository del tuo sito crea una cartella chiamata: geometria-adventure
2. Carica dentro la cartella i tre file di questo pacchetto.
3. Il gioco sarà raggiungibile a:
   https://TUO-UTENTE.github.io/NOME-REPOSITORY/geometria-adventure/
   Se il repository è il sito principale (TUO-UTENTE.github.io), il percorso sarà:
   https://TUO-UTENTE.github.io/geometria-adventure/

PER AGGIUNGERLO ALLA HOMEPAGE
Aggiungi una nuova card dentro la griglia dei giochi, usando questo link:
   ./geometria-adventure/index.html

NOTE
- Il gioco funziona senza librerie JavaScript esterne.
- Il punteggio e i mondi visitati vengono salvati nel browser tramite localStorage.
- La lavagna funziona con mouse, touch e penna.
- Il tangram è libero: non verifica automaticamente una sagoma precisa, lascia spazio alla creatività.
