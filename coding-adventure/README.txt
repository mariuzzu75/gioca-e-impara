INSTALLAZIONE SU GITHUB PAGES
1. Estrai la cartella "coding-adventure".
2. Carica la cartella nella radice del repository GitHub, accanto alle altre webapp.
3. Fai commit e attendi l'aggiornamento di GitHub Pages.
4. Il link sarà: https://TUO-UTENTE.github.io/NOME-REPOSITORY/coding-adventure/

COLLEGAMENTO DALLA HOMEPAGE
Aggiungi una scheda alla griglia delle app con href="./coding-adventure/index.html".

COME SI GIOCA
- Scegli un personaggio e una modalità.
- Genera un percorso casuale.
- Inserisci le frecce nell'ordine corretto e premi AVVIA.
- Oppure scegli "Esegui un passo alla volta" e avanza con il pulsante dedicato.
- "Annulla" rimuove l'ultima istruzione; "Cancella" elimina tutto il programma.
- Nella modalità Sfida compare "Ripeti ultimo comando ×3".
- Le gemme sono sul percorso corretto: raccoglierle è un obiettivo bonus.
- Se una freccia porta fuori dalla griglia o contro una roccia, il gioco spiega l'errore.

MODALITÀ
- Principiante: 4×4, senza ostacoli.
- Esploratore: 5×5, 3 ostacoli.
- Programmatore: 6×6, 6 ostacoli.
- Sfida: 6×6, 7 ostacoli e comando Ripeti ×3.

Il percorso è generato con un algoritmo che garantisce una strada libera tra partenza e arrivo. Gli ostacoli sono collocati fuori da quella strada.
